## 🎆 Diwali Firecracker Sound

Light up your code with the sound of celebration!
This project brings **realistic Diwali firecracker effects** — designed for apps, games, and interactive Diwali greetings.
https://irfanahammad.github.io/Happy-diwali/
---

### 🔊 Features

* Authentic **Diwali firecracker sounds** — bombs, chakris, flowerpots, sparklers, and more.
* **High-quality WAV/MP3 files** (optimized for quick load).
* Optional **looping and volume controls**.
* Works across **web, mobile, and embedded apps**.
* Plug-and-play: drop it in and trigger with a single function.

---

### ⚙️ Setup

1. Clone or download the project:

   ```bash
   git clone https://github.com/irfanahmed0019/happy-diwali.git
   cd happy-diwali
   ```

2. Import the sounds into your project:

   ```js
   import bomb from './sounds/bomb.mp3'
   import sparkler from './sounds/sparkler.mp3'
   ```

3. Trigger playback (example in JS):

   ```js
   const audio = new Audio(bomb)
   audio.play()
   ```

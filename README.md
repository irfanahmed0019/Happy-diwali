# Luminous Diwali

A Diwali greeting page with a neon "HAPPY DIWALI" title, glowing string lights and a particle effect. Plain HTML, CSS and JavaScript, no build step.

## Files

- `index.html` - page structure and the neon title
- `style.css` - neon text, bulb glow and layout
- `script.js` - loads the particle effect

## Run locally

```sh
git clone https://github.com/irfanahmed0019/Happy-diwali.git
cd Happy-diwali
```

Open `index.html` in a browser.
